# Attribution and scope

Apache-2.0 covers this repository's application code and authored demonstration assets.
The owner-supplied project avatar (docs/assets/bot-avatar.jpg) is a separate
branding asset; the code license does not grant rights to that image.
No model weights, model runtimes, private transcripts, vendor source trees or
experimental model checkpoints are distributed here. Downloaded components
retain their own licenses; this license does not relicense them.

- [llama.cpp](https://github.com/ggml-org/llama.cpp): local chat runtime.
- [whisper.cpp](https://github.com/ggml-org/whisper.cpp): optional speech recognition.
- [MFLUX](https://github.com/filipstrand/mflux): optional image adapter runtime.
- [httpx](https://github.com/encode/httpx), [python-dotenv](https://github.com/theskumar/python-dotenv): Python dependencies.
- [Qwen3.5-9B GGUF distribution](https://huggingface.co/unsloth/Qwen3.5-9B-GGUF): suggested neutral starting model; downloaded separately.

The shipped Starharbor / Aoba world and Lin Qing demonstration profile are
fictional examples. Character names, places and dialogue are not imported from
a user's live database. Psychological references inform engineering choices;
the numeric rules are neither validated psychological scales nor a clinical model.
See docs/REFERENCES.md. The suggested public model has not undergone the same
local generation trials as the developer's previous private fine-tune.

The owner-selected avatar is presented as “Malfoid｜性轉馬份”, a fan-character branding image. This is separate from the original-world demonstration profile; no official affiliation is claimed.
