# Public development guide

This is a standalone alpha. Do not import a developer's live databases, prompts,
model caches, backup trees or personal configuration. Public examples must be
synthetic, with explicitly adult characters. Adult mode defaults off.

Decision rules own action selection; delivery rules own tone; the Writer phrases
the decision. Current state is authoritative. A proposal is not a completed action.
Diagnostic records are inspection data, never a memory source. Keep model calls
out of deterministic gates and document any added latency.

Use temporary databases for tests. Do not contact Telegram, run private dialogue
replays or send data to external models without explicit authorization. Never
publish .env, database files, outputs or model weights. Run synthetic tests and
scripts/check_public.py before a release. Do not describe an experiment as deployed.
