# Security and privacy

Do not attach a real database, Prompt archive, .env or unredacted debug screenshot
to a public issue. The local diagnostic archive deliberately contains private
content. Use fictional reproductions instead.

Telegram carries messages through Telegram servers. Local inference alone does
not make the transport private. Optional RSS/search and explicitly requested
external reviews have separate network behavior. Never put credentials into a
character profile.

Services bind to loopback. Do not publicly expose the workbench, model API or
Prompt viewer. This alpha is single-user and has not received an independent
security audit. Avoid enabling tools or external review on an untrusted character
configuration. For sensitive reports, use GitHub private vulnerability reporting
if the maintainer enables it; no private reporting channel is promised yet.
